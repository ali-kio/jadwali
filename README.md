# جدولي — منظّم الفصل الدراسي

تطبيق ويب عربي (RTL) للطلاب: الجدول الأسبوعي، الاختبارات النهائية، الغياب، الفصول، وأذكار الصباح والمساء.
بدون سيرفر وبدون حسابات — كل بيانات الطالب تبقى في متصفحه، ويشتغل بدون إنترنت بعد أول فتح.

---

## التشغيل

التطبيق ملفات ثابتة، بس لازم يُفتح عبر **سيرفر** (وليس نقرتين على `index.html`)
لأن عامل الخدمة (offline) لا يعمل مع `file://`.

```bash
# أي وحدة من هذي تكفي
python3 -m http.server 8080
npx serve .
```

ثم افتح `http://localhost:8080`.

### النشر
ارفع محتويات المجلد كما هو على أي استضافة ثابتة:
GitHub Pages أو Netlify أو Vercel أو Cloudflare Pages — ما يحتاج أي إعداد.
بعد النشر يقدر الطالب يضيفه للشاشة الرئيسية من المتصفح فيصير مثل التطبيق.

## إضافة المقررات — ثلاث طرق

**1) بحث في المقررات (الأسرع).**
يكتب الطالب رمز المقرر أو اسمه أو اسم الدكتور، تطلع له السكاشن بكل تفاصيلها
(نوع الحصة، الأيام، الأوقات، القاعات، الدكتور، الامتحان النهائي)، يختار شعبته ولون المقرر → «أضف لمقرراتي».
الكتالوج المدمج يغطي **كلية تقنية المعلومات — 2026/2027 الفصل الأول** (181 مقرراً، 348 شعبة).

**2) لصق من UCS** — لبقية الكليات أو لفصل جديد.
يفتح [ucs.uob.edu.bh](https://ucs.uob.edu.bh)، يعرض السكاشن، ينسخ الصفحة (Ctrl+A ثم Ctrl+C) ويلصقها.
أو يستعمل «أداة الاستخراج» (bookmarklet) الموجودة داخل التطبيق فتنسخ الصفحة بضغطة.
المحلّل يفهم صيغة الموقع حرفياً: `Class Type / Day / Time / Location / Exam Date / Section / Instructor`.

> **ليش لصق وليس جلب مباشر؟** موقع UCS يبني نتائجه عبر POST + ViewState،
> والمتصفح يمنع أي موقع من قراءة موقع آخر (CORS). فبدون سيرفر وسيط يبقى اللصق
> هو الطريق المضمون — ولهذا أُدمج الكتالوج حتى ما يحتاجه أغلب الطلاب أصلاً.

**3) إدخال يدوي** — لأي مقرر خارج النظام.

بعد الإضافة كل شي قابل للتعديل: أوقات الحصص، القاعة، النوع، المدرّس، الشعبة، اللون، وحتى موعد الامتحان.

## تحديث الكتالوج لفصل جديد

افتح `js/catalog.js` وعدّل `CATALOG_RAW`. الصيغة سطر بسطر:

```
C|الرمز|الاسم|القسم|تاريخ النهائي|من|إلى|المتطلبات
S|الشعبة|المدرّس
M|L أو B|الأيام|من|إلى|القاعة
A|الرمز|الاسم|القسم|رمز مقرر آخر      ← مقرر بنفس سكاشن غيره
```

الأيام أرقام متلاصقة: `0` أحد، `1` إثنين، `2` ثلاثاء، `3` أربعاء، `4` خميس.
فـ `M|L|024|13:00|13:50|S40/2048` تعني محاضرة أحد وثلاثاء وخميس.
وعدّل `Catalog.META` في آخر الملف (السنة والفصل).

## البيانات والنسخ الاحتياطي

كل شي في `localStorage` تحت المفتاح `jadwali.uob.v2`.
من الإعدادات: **تنزيل نسخة احتياطية** (ملف JSON) و**استعادة نسخة** و**مسح كل شي**.
لو مسح الطالب بيانات المتصفح تروح البيانات — فالنسخة الاحتياطية مهمة.

## ملاحظات تقنية

- سكربتات كلاسيكية (بدون ES modules) حتى يشتغل حتى من `file://` — بدون بناء أو أدوات.
- لا Tailwind ولا مكتبات أيقونات خارجية؛ الأيقونات SVG داخل `icons.js`.
- الخطوط من Google Fonts وتُخزَّن في الكاش بعد أول تحميل، ولها بدائل من النظام.
- يحترم `prefers-reduced-motion` و`prefers-color-scheme`، وفيه تركيز واضح للكيبورد.
- عند إضافة مقرر ينبّهك التطبيق إذا كان وقته يتعارض مع مقرر عندك.
